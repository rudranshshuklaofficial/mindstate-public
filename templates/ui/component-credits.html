Components and credits

MindState adapts selected free components from Arc UI / UIArc by Elia Kuratli, under the MIT licence. Our cream, forest, ink and yellow palette, Google Sans Flex and Instrument Serif remain the design system. No global UIArc foundation or reset is loaded.

React islands enhance Django forms; the server still validates submissions and controls access. Motion is limited to quiet, short state feedback, with immediate reduced-motion states. Review appearance navigation remains ordinary links.

Underlying dependencies include React, Motion, Radix UI and Lucide. Applicable upstream notices remain with the source. Previous Rare UI, shadcn component wrappers and Motion Primitives disclosure are replaced after parity checks; the shadcn CLI is only an installation tool. See frontend/README.md for adaptation and upgrade instructions.

We intentionally retain the existing gallery, notebook, scrapbook and member-card renderers. Toasts, steppers, radio cards, password fields and loading skeletons are not added merely to replace working controls.
